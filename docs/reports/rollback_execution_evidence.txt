1. ROOT CAUSE & PERMANENT RESOLUTION
--------------------------------------------------------------------------------
Root Cause:
Models 'models/v0001/manifest.json', 'models/v0002/manifest.json', and
'models/v_promotable/manifest.json' had declared 'artifact_hash' values computed
from Windows CRLF (\r\n) file encodings. In Git and on Linux/CI checkouts,
repository objects are stored with LF (\n). When evaluated on Linux or fresh
clones, 'compute_artifact_hash()' hashed LF bytes, causing 'validate_rollback_target()'
to detect a mismatch between declared and computed hashes and fail closed before
the pointer switch.

Resolution Implemented:
1. 'compute_artifact_hash()' in 'app/model/train.py':
   Explicitly normalizes text files (.json, .txt) by replacing b'\r\n' with b'\n'
   before SHA-256 digest computation, ensuring bit-for-bit identical hashes across
   Windows, Linux, macOS, and Git checkouts. Binary files ('model.joblib') remain
   strictly binary.
2. '.gitattributes' created at repository root:
   Enforces 'eol=lf' for text files and 'binary' for '*.joblib', guaranteeing
   canonical LF checkouts cross-platform.
3. Package Files Normalized & Authoritative Hashes Certified:
   All behavior-defining text files in 'models/v0001/', 'models/v0002/', and
   'models/v_promotable/' normalized to LF on disk. Manifests updated with
   authoritative LF hashes:
   - models/v0001:        sha256:19baaf437a2e6158fe4cbb542ddc7a7a61474076d74839eaea932d4d3c94ff5f
   - models/v0002:        sha256:1eb0dc7488fddc616f0be7413e9cc48fd4139932ff43da81927e2a335d714d62
   - models/v_promotable: sha256:f004e6273345a37ac01e55c60209b231448fa85f73dada908f07e412c07a6061
4. 'scripts/make_submission.py' ('make run'):
   Updated to emit 'backlog_report.json' (first scored week 2026-02-02) alongside
   'predictions.csv', closing the operational backlog intelligence gap for fresh
   clones.
5. 'tests/unit/test_frontend_shell.py':
   Hermetically isolated 'test_replay_provenance_truthful_nullability' to a temporary
   clean root so pre-existing rollback history in the workspace does not mask
   baseline nullability assertions.
